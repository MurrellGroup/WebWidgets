Organizational Network Builder

Hub-and-spokes editing with arbitrary hubs, manual layout, force layout, frozen nodes, and exact JSON save/load.

Build

Click to select. Shift+click to add or remove from the selection. Double-click a label to edit it. In Connect mode (C), click any source node, then any target — e.g. a spoke to a different hub. Drag the background to pan; use the wheel to zoom.

Force layout

Controls target center-to-center length for every connection that does not have Override default link distance checked. Frozen nodes will not move; links with two frozen endpoints cannot change length.

Edge avoidance pushes nodes away from connection lines they are not part of. This is unrelated to label text inside nodes.

Edit

Nothing selected — changes apply to every node and every connection, and become the default for new items. Click one item to edit it individually, or Shift+click to edit several at once.

Node

Label layout

Label inset is the main control for how close text can get to the node boundary. Larger inset wraps earlier and keeps more clear space at the edges.

Soft shadow under the node shape. Uncheck to disable; applies to SVG export too. With nothing selected, toggling this updates all nodes.

Connection

Bezier links are anchored at node centers but draw from shape edge to shape edge (arrows sit on the boundary). Drag the blue control points, or reset to recompute the route.
